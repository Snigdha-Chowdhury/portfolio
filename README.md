# Snigdha Chowdhury | Portfolio

A personal portfolio website for Snigdha Chowdhury, built as a static one-page site with HTML, Tailwind CSS, and vanilla JavaScript.

## Overview

This portfolio showcases:
- software engineering experience and focus areas
- selected work and projects
- writing and technical content
- contact and social links

It is designed with a premium dark-and-warm aesthetic, responsive layout, smooth motion, and SEO-ready metadata for GitHub Pages.

## Tech Stack
- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- Font Awesome icons
- GitHub Pages hosting

## Project Structure
- [index.html](index.html) — main portfolio content and SEO metadata
- [css/style.css](css/style.css) — custom styling, layout polish, and animations
- [js/main.js](js/main.js) — mobile menu behavior, smooth scroll, and reveal interactions
- [favicon.svg](favicon.svg) — browser tab icon
- [robots.txt](robots.txt) — crawl rules for search engines
- [sitemap.xml](sitemap.xml) — sitemap for indexing

## Local Preview

Because this is a static HTML/CSS/JS portfolio, you can preview it by opening [index.html](index.html) directly in any browser.

No installation or build step is required.

## Deployment

This project is configured for GitHub Pages as a project site. The live URL is:

https://snigdha-chowdhury.github.io/portfolio/

## Notes

- Assets are referenced in a GitHub Pages-safe way to work correctly under the /portfolio/ project path.
- Meta tags, Open Graph data, and schema markup are included to improve discoverability.
- The layout is responsive and optimized for desktop and mobile screens.
